# 🤖 Hassan Agent - دستیار هوش مصنوعی شخصی

یک Agent هوش مصنوعی قدرتمند برای مدیریت سایت، ایمیل، خرید و ارتباطات از طریق تلگرام.

## ✨ قابلیت‌ها

| قابلیت | توضیح |
|--------|-------|
| 👥 مدیریت کاربران | دیدن کاربران جدید، پیشرفت، ارسال پیام |
| 📧 ایمیل | خواندن، جستجو، ارسال ایمیل (Gmail) |
| 🌐 اینترنت | جستجو، خواندن صفحات وب |
| 📦 ردیابی | کد رهگیری پست ایران |
| ✈️ بلیط و هتل | جستجو در سایت‌های ایرانی |
| 💱 نرخ ارز | دریافت نرخ لحظه‌ای |
| 🧠 حافظه | ذخیره اطلاعات مهم بین مکالمات |
| 📱 تلگرام | رابط اصلی دوطرفه |

## 🚀 نصب سریع

1. **نصب:**
```bash
npm install
```

2. **تنظیم `.env`** با مقادیر زیر:
```env
GEMINI_API_KEY=...
TELEGRAM_BOT_TOKEN=...
TELEGRAM_OWNER_ID=...
```

3. **اجرا:**
```bash
npm start
```
یا روی **start.bat** دوبار کلیک کن.

## ⚙️ راهنمای تنظیمات

### Gemini API Key
از [aistudio.google.com/app/api-keys](https://aistudio.google.com/app/api-keys) بگیر.

### ربات تلگرام
1. به [@BotFather](https://t.me/BotFather) برو و `/newbot` بزن
2. توکن رو در `TELEGRAM_BOT_TOKEN` بذار

### آیدی تلگرام خودت
از [@userinfobot](https://t.me/userinfobot) بگیر → `TELEGRAM_OWNER_ID`

### Gmail (اختیاری)
1. تأیید دومرحله‌ای رو فعال کن
2. از [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) یک App Password بساز
3. رمز 16 کاراکتری رو در `EMAIL_PASSWORD` بذار

### API سایت (اختیاری)
اگه سایتت API داره، `SITE_API_URL` و `SITE_API_KEY` رو تنظیم کن.

```
├── index.js                 # نقطه شروع

│   │   └── masterAgent.js   # هسته اصلی AI + Function Calling

│   │   └── webTools.js      # مرورگر، اینترنت، ردیابی
│   └── database/
│       └── db.js            # SQLite - حافظه و تاریخچه
├── data/                    # دیتابیس (خودکار ساخته می‌شه)

```
